# FamilyHub v1.0.0

Data release: 2026-08-08
Versione: `1.0.0`
Stato: baseline stabile iniziale

## Sintesi
La release `1.0.0` formalizza la prima baseline stabile di FamilyHub.

Questa baseline include il perimetro funzionale e infrastrutturale necessario per:
- gestione minori e profilo esteso
- gestione documentale con regole di accesso sensibili
- gestione uscite, attività, avvicinamenti e diario educativo
- gestione utenti, ruoli, assegnazioni e audit
- gestione educatori, turni e timesheet
- deploy locale Docker e deploy remoto Docker production

## Componenti inclusi
- backend API Laravel
- frontend React/Vite
- PostgreSQL
- Redis
- storage S3 compatibile con MinIO locale
- ClamAV per scansione documentale
- Nginx reverse proxy applicativo

## Scope della baseline 1.0.0
### Sicurezza
- MFA disponibile e integrata nel login
- auditing esteso su accessi e operazioni sensibili
- RBAC per accesso ai moduli e ABAC per visibilità documentale
- stack production documentato con hardening iniziale

### Operations
- Docker locale per sviluppo
- Docker production con immagini immutabili
- checklist VPS Debian/OVH/Aruba
- template `.env.prod` per ambienti remoti

### Documentazione
- README installazione
- hardening produzione
- checklist nuovo ambiente
- handoff UX/API accumulati nel repository

## Convenzione release future
Da `1.0.0` in poi:
- `major`: modifiche incompatibili o ripensamenti architetturali forti
- `minor`: nuove funzionalità compatibili
- `patch`: bugfix, hardening, correzioni non breaking

## Requisiti di release management
Ogni release futura deve includere:
1. aggiornamento `VERSION`
2. aggiornamento `CHANGELOG.md`
3. release note dedicata in `docs/releases/`
4. elenco impatti backend/frontend/infrastruttura
5. note di migrazione se necessarie
