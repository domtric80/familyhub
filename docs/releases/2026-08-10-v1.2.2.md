# FamilyHub v1.2.2 — 2026-08-10

## Sintesi

Release patch dedicata a stabilizzazione UX/backend del modulo geografia e alla correzione del flusso anagrafica `Educatori`.

Obiettivo principale:

- eliminare caricamenti massivi non sostenibili del dataset città
- rendere la navigazione geografica più chiara e recuperabile
- riallineare frontend, backend e documentazione di handoff

## Contenuto release

### 1. Educatori — lookup città nascita sicuro
- il campo `Città nascita` non precarica più tutte le città del database
- introdotta ricerca asincrona con attivazione dopo almeno 2 caratteri
- mantenuta la compatibilità con i record esistenti: la città già salvata viene risolta tramite `id`

### 2. Geografia — UX di navigazione
- breadcrumb navigabili nella pagina geografia
- breadcrumb navigabili anche nel dettaglio città
- ripristino dello stato selezionato durante il ritorno dai livelli inferiori della gerarchia

### 3. Organizzazioni — frontend CRUD
- abilitati frontend `Modifica` ed `Elimina`
- rimosso messaggio obsoleto che indicava endpoint backend non disponibili
- corretto il form con input controllati per evitare falsi errori di validazione

### 4. Messaggistica — encoding
- risolto il problema di visualizzazione di caratteri speciali corrotti nel dettaglio conversazione

## Moduli coinvolti

- `Anagrafiche / Geografia`
- `Educatori`
- `Organizzazioni`
- `Messaggistica interna`

## Contratti e impatti API

### Lookup città
Endpoint interessato:

- `GET /api/lookups/cities`

Comportamento aggiornato:

- senza filtri e senza query → `[]`
- con `id` → restituisce la città selezionata
- con `q` → restituisce massimo 25 risultati per ricerca
- supportati anche `province_id`, `region_id`, `country_id`, `limit`

## Sicurezza

- eliminato il preload massivo del dataset città che portava a `Allowed memory size exhausted`
- ridotta l'esposizione di risposte geografiche troppo grandi lato backend
