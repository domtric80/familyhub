# FamilyHub v1.5.2

Data release: 2026-08-30

## Sintesi

Release patch dedicata alla stabilizzazione della supply chain, alla firma automatizzata delle release, alla bonifica della baseline security e alla separazione esplicita tra lettura e download nella policy ABAC documentale.

## Modifiche principali

- Immagini Docker e servizi infrastrutturali referenziati con digest espliciti.
- Workflow `familyhub-release` predisposta per tag GPG firmati e verificati prima della pubblicazione GitHub.
- Documentazione release e hardening aggiornata per produzione e CI.
- Build backend produzione resa piu prevedibile evitando script Composer durante l'immagine.
- Esclusione di `backend/public/storage` dal contesto Docker.
- Classificazioni documentali aggiornate con policy separate per lettura/preview e download.
- OpenAPI e handoff UX aggiornati per il contratto ABAC delle classificazioni.

## Sicurezza

- Secrets GitHub Actions richiesti: `RELEASE_GPG_PRIVATE_KEY` e `RELEASE_GPG_PASSPHRASE`.
- Controlli previsti prima del tag: backend test, frontend build, Composer audit, npm runtime audit.
- Nessun bypass amministrativo richiesto per il rilascio.
- Il backend forza `allowed_download_role_codes` come sottoinsieme di `allowed_role_codes`.

## Database

- Nessuna migrazione.
- Nessun reset dati.
- Nessun reseed.

## Operazioni post-deploy

```bash
git pull
docker compose build
docker compose up -d
docker compose exec app php artisan migrate --force
docker compose ps
```

## Verifiche consigliate

- Login admin e utente operativo.
- Health servizi applicazione, PostgreSQL, Redis, MinIO/S3 e antivirus.
- Upload, preview e download documenti secondo RBAC/ABAC.
- Accesso a Minori, Turni/Timesheet, Avvicinamenti, Diario educativo e Messaggistica.
- Gestione classificazioni documentali con ruoli lettura e ruoli download separati.
