# FamilyHub v1.5.1

Data di rilascio: 26 agosto 2026

## Obiettivo

`v1.5.1` è una patch release di sicurezza e governance. Corregge gli alert stored XSS rilevati da CodeQL, applica sanitizzazione HTML in profondità su frontend e backend e rende obbligatorio il processo di revisione indipendente delle modifiche.

## Sicurezza applicativa

- DOMPurify centralizzato protegge editor rich text, messaggi interni e preview DOCX;
- l'allowlist ammette esclusivamente i tag di formattazione previsti e link `http`, `https` e `mailto`;
- il backend sanitizza i messaggi prima della cifratura e nuovamente durante la lettura, proteggendo anche contenuti storici;
- i tre alert CodeQL XSS `#17`, `#18` e `#19` risultano chiusi automaticamente;
- npm audit runtime, CodeQL JavaScript/TypeScript, CodeQL GitHub Actions e Semgrep non hanno rilevato vulnerabilità bloccanti.

## Governance e supply chain

- `@tuxlbit` è CODEOWNER globale con ruolo Write;
- ogni pull request verso `master` richiede approvazione CODEOWNER e approvazione dell'ultimo push;
- i commit e i tag devono avere una firma SSH verificata;
- non esistono bypass amministrativi permanenti;
- restano obbligatori backend test, Composer audit, frontend build, npm audit, CodeQL, Dependency Review e Semgrep.

## Compatibilità e dati

- nessuna breaking change API;
- nessuna migrazione database;
- nessun reset, reseed o intervento distruttivo sui dati;
- compatibilità invariata con lo stack Docker FamilyHub `1.5.x`.

## Aggiornamento

1. eseguire e verificare un backup del database e dello storage documentale;
2. aggiornare il codice al tag `v1.5.1`;
3. ricostruire le immagini backend e frontend per includere le nuove dipendenze;
4. avviare lo stack senza eseguire `migrate:fresh` o reseed;
5. verificare login/MFA, messaggistica interna e preview documenti;
6. controllare la pagina Health servizi e i log applicativi.

Non sono richieste migrazioni per questa release.
