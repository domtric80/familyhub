# FamilyHub v1.1.0

Data release: 2026-08-08
Versione: `1.1.0`
Stato: minor release funzionale

## Sintesi
La release `1.1.0` estende la baseline `1.0.0` con una nuova area amministrativa di sistema focalizzata su:

- monitoraggio salute servizi
- gestione configurazione storage documentale
- integrazione completa backend/frontend/UX per queste due funzioni

## Novit? principali

### Sistema > Health Servizi
- snapshot stato servizi da backend
- refresh manuale con audit
- KPI `ok`, `warning`, `error`, `not_configured`
- dettaglio tecnico espandibile per singolo servizio

### Sistema > Configurazione Storage
- fallback esplicito tra configurazione runtime `ENV` e configurazione `DB`
- CRUD configurazioni storage S3 compatibili
- test connessione per singola configurazione
- attivazione configurazione DB come sorgente runtime corrente
- visualizzazione sola mascherata delle credenziali

## Sicurezza
- credenziali storage cifrate a riposo con `Crypt`
- segreti non restituiti in chiaro dalle API
- permessi dedicati:
  - `system_health.read`
  - `system_health.run`
  - `system_storage.read`
  - `system_storage.create`
  - `system_storage.update`
  - `system_storage.activate`
  - `system_storage.test`
  - `system_storage.delete`
