# FamilyHub v1.1.1

Data release: 2026-08-08
Versione: `1.1.1`
Stato: patch release sicurezza

## Sintesi
La release `1.1.1` consolida la `1.1.0` con una bonifica mirata delle dipendenze applicative e con una riduzione della superficie di attacco lato frontend.

## Obiettivi della patch
- chiudere gli advisory aperti rilevati da `npm audit`
- chiudere gli advisory aperti rilevati da `composer audit`
- evitare preview browser basate su librerie spreadsheet vulnerabili o non strettamente necessarie, mantenendo la consultazione sicura dei file XLSX
