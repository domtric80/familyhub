# FamilyHub v1.2.0 — 2026-08-09

## Sintesi

Release minor dedicata alla chiusura operativa del blocco:

- `Turni / Timesheet`
- `Messaggistica interna cifrata`

con completamento congiunto backend + UX.

## Contenuto release

### 1. Turni / Timesheet
- aggiunto export `PDF` mensile delle presenze
- mantenuti gli stessi preset amministrativi del CSV:
  - `payroll`
  - `review`
  - `labor_consultant`
- audit dedicato sull’azione di export
- allineato il frontend `Export presenze` con selezione formato `CSV/PDF`

### 2. Messaggistica interna
- completati filtri lista:
  - `topic`
  - `archived`
  - `classification_code`
- completata archiviazione thread
- aggiunti metadati ruolo nei partecipanti selezionabili
- introdotta classificazione ABAC dei thread:
  - `internal`
  - `restricted`
  - `clinical`
  - `judicial`

### 3. Sicurezza e policy
- i thread sensibili ora rispettano la stessa policy ABAC di documenti e note
- il backend impedisce:
  - creazione thread con classificazione non ammessa al creatore
  - selezione di partecipanti non autorizzati alla classificazione
  - apertura di thread da parte di utenti partecipanti ma non autorizzati al livello di classificazione

## Retrocompatibilità
- creazione thread senza `classification_code`: il backend usa `internal`
- nessun reset dati eseguito
- migrazione additiva applicata su DB esistente
