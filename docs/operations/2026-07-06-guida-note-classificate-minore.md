# Guida operativa - Note classificate del minore

Data: 2026-07-06
Ambito: scheda minore, contenuti riservati, équipe

## 1. A cosa servono

Le note classificate del minore servono a registrare osservazioni sensibili in modo strutturato e coerente con la politica documentale del sistema.

## 2. Classificazioni disponibili

- `Interno`
- `Riservato`
- `Clinico`
- `Giudiziario`

## 3. Regola pratica

Le note seguono la stessa logica dei documenti:

- chi può leggere una certa classificazione documentale può leggere anche le note della stessa classificazione
- se la classificazione non è ammessa per il ruolo, la nota non viene mostrata

## 4. Protezione del contenuto

Le note vengono salvate in forma cifrata dal backend.

L’operatore vede solo il contenuto che il sistema decide di mostrargli dopo i controlli autorizzativi.
